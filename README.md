# Alegra Design Skills

Skills de Claude Code para diseñadores y no-ingenieros del equipo.

## Instalar

En Claude Code, corre:

```
/plugin marketplace add juan-bermeo-alegra/save-design-changes
/plugin install safe-design-changes
```

Reinicia Claude Code. Listo — la skill se activa sola cuando pidas un cambio de front-end.

Funciona igual en **Mac y Windows**. No tienes que tocar carpetas ni rutas.

## Skills incluidas

- **safe-design-changes** — hace cambios de UI/texto de forma segura: imita el código del proyecto, verifica con el build, y se detiene (escalando a un ingeniero) si el cambio toca config, datos, dinero, auth o lógica de negocio.

## Actualizar

```
/plugin marketplace update save-design-changes
```
